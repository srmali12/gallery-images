# gallery-images
🖼️ Image Gallery with jQuery
This project is a responsive image gallery built using HTML5, CSS3, Bootstrap, and jQuery. It showcases a smooth and interactive interface where users can view images with transition effects and filter them based on categories.

✨ Features
✅ Responsive design using Bootstrap

✅ Smooth jQuery transitions (fade, slide, etc.)

✅ Category-based image filtering

✅ Organized file structure with a dedicated images/ folder

📁 Technologies Used
HTML5

CSS3

Bootstrap

jQuery
